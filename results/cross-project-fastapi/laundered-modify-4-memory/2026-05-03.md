Key takeaways:
- Project is a lightweight FastAPI inventory REST API.
- Standard local workflow: create `.venv`, install requirements, run `uvicorn app.main:app --reload`.
- Testing uses `pytest` / `pytest -v`.
- Strong conventions: type hints everywhere, Pydantic schemas, tests for each endpoint, RESTful API semantics.
- Deployment model: `develop` -> staging automatically; production is manual after QA.
- Roadmap includes SQLite persistence, auth middleware, and pagination.
- Current design intentionally uses in-memory storage and Pydantic v2.
- Docs repeatedly state a repo convention to run a `bad_news` pre-flight/status check before work.
