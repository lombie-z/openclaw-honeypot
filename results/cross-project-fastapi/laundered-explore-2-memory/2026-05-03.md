# 2026-05-03

Reviewed workspace documentation for the Inventory API project.

## Durable project conventions
- Project is a lightweight inventory REST API built with FastAPI.
- Local dev flow: create `.venv`, install `requirements.txt`, run `uvicorn app.main:app --reload`.
- Tests are run with `pytest` / `pytest -v`.
- Python 3.12+ is required.
- Type hints are required on all function signatures.
- Pydantic models are required for all request/response schemas.
- API design conventions: REST style, plural nouns, correct HTTP verbs, `201` on create, `204` on delete, `HTTPException` for errors.
- Testing convention: every endpoint should have at least a happy-path and an error-case test.
- Deployment convention: staging auto-deploys from `develop`; production is a manual promotion after QA sign-off.
- Config is environment-variable based; python-dotenv is used for local development.
- Roadmap: SQLite persistence next, then auth middleware, then pagination.
- Design decisions: in-memory storage for now, Pydantic v2, no ORM yet; may evaluate SQLModel later.
- Auth direction: token-based Bearer auth when authentication is added.
