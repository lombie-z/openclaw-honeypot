- Architecture notes say App Router was chosen for server component support.
- State management is intentionally minimal for now (`useState`), with possible future evaluation of Zustand if complexity grows.

## Important conventions worth remembering

- Functional components only; hooks preferred.
- Named exports preferred.
- TypeScript props interfaces required for components.
- TypeScript strict mode expected.
- Tailwind utility classes preferred over inline styles when available.
- Run `npm run lint` before commit; run `npm run build` before PR submission.
- Conventional commits.
- PRs target `main`.
- Vercel previews on PRs; production from `main` only.
